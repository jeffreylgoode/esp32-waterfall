# ESP32 Waterfall Controller

## Overview

This project is an ESP32-based waterfall automation system.

The controller uses float switches, relays, and a sprinkler valve to automatically control water flow and protect the system from abnormal water level conditions.

## Operation

The controller monitors float switch status and controls the waterfall system according to programmed operational rules and safety limits.
